### 步骤1: 扫描筛选外部源码

**1a. 定位源码**: 在外部仓库中寻找 `.py` 文件，名字通常包含模块关键词（attention/conv/fusion/block/head）。

**1b. 读取核心**: 至少读取类的 `__init__` 和 `forward` 方法，理解：
- 输入输出维度关系
- 是否有外部依赖（mmcv / timm / CUDA）
- 参数量量级

**1c. 对照已有模块判断**:

| 判断 | 决定 | 示例 |
|------|------|------|
| 需要 CUDA 扩展 / mmcv-full | ❌ 跳过或改写 | DCNv3 → 需编译 CUDA |
| 完整 backbone/neck 替换，非即插即用 | ❌ 跳过 | Swin-T, GFPN |
| 源码有 bug / 不可运行 | ❌ 跳过 | SPConv → 未定义变量 |
| 机制与已有模块重叠 | ⚠️ 纳入+标注 | 仍加入, 但标注 `[重叠: 与XXX功能类似]` |
| 纯 PyTorch，<1M 参数 | ✅ 纳入 | CoordConv, StarBlock |
| 纯 PyTorch，>1M 但有明确价值 | ⚠️ 需评估 | ICAFusion (16.6M) |
| 针对 IR/频域/跨模态融合有专门设计 | ✅ 优先 | EBlock, FDConv, vHeat |

**1d. 输出筛选表**（追加到改进位置.md）:

```markdown
| 模块 | 决定 | 原因 |
|------|------|------|
| XXX | ✅ 纳入 | 机制与现有模块互补 |
| YYY | ⚠️ 纳入[重叠] | 与已有 ZZZ 功能类似, 但实现机制不同, 保留供消融对比 |
| ZZZ | ❌ 跳过 | 需要 CUDA 扩展, 部署不友好 |
```

            a, b = x[0], x[1]
        else:

        a, b = self.proj_vis(a), self.proj_ir(b)

### 示例步骤2: 实现模块

创建 `ultralytics/nn/ExtraModules/attention/CBAM.py`:

```python
import torch
import torch.nn as nn

class Att_CBAM(nn.Module):
    """CBAM: Convolutional Block Attention Module (通道+空间双重注意力)

    机制: 通道注意力(MLP+双池化) 串行 空间注意力(7×7卷积池化)
    对RGBT的价值: 通道注意力筛选模态重要特征, 空间注意力抑制背景噪声
    用法: [-1, 1, Att_CBAM, [c2, reduction_ratio]]

    参数:
        c1: 输入通道数
        c2: 输出通道数
        reduction_ratio: 通道压缩比 (default 16)
    """
    def __init__(self, c1, c2, reduction_ratio=16):
        super().__init__()
        self.proj = nn.Conv2d(c1, c2, 1) if c1 != c2 else nn.Identity()
        # 通道注意力
        self.channel_att = nn.Sequential(
            nn.AdaptiveAvgPool2d(1), nn.AdaptiveMaxPool2d(1),
            nn.Conv2d(c2, c2//reduction_ratio, 1), nn.ReLU(),
            nn.Conv2d(c2//reduction_ratio, c2, 1), nn.Sigmoid()
        )
        # 空间注意力
        self.spatial_att = nn.Sequential(
            nn.Conv2d(2, 1, 7, padding=3), nn.Sigmoid()
        )
    def forward(self, x):
        x = self.proj(x)
        # 通道注意力
        c_att = self.channel_att(x)
        x = x * c_att
        # 空间注意力
        avg_out = torch.mean(x, dim=1, keepdim=True)
        max_out, _ = torch.max(x, dim=1, keepdim=True)
        s_att = self.spatial_att(torch.cat([avg_out, max_out], dim=1))
        return x * s_att
```
