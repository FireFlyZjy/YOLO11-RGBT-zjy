**基线 (origin)**: mAP50=0.8495, mAP50-95=0.4900, Params=15.24M

### 2.3 关键结论

1. **DASI 是当前最强模块** (mAP50-95=0.5232, 较基线 +6.8%)。其源码注释明确标注
   "红外小目标暴力涨点"，Bag 子模块用 dilation=2/4/6/8 的多尺度空洞卷积，
   对小目标的多尺度特征提取极为有效。**这是卫星图像小目标检测的首选起点**。

2. **COI 轻量且高效** (mAP50-95=0.5088~0.5216)。仅 14.96M 参数，三重残差
   (恒等+深度卷积+1x1)，适合嵌入 backbone 浅层。延长训练到 150ep 还能再涨 +1.3%。

3. **Aggregation / ProgressiveAgg 是颈部多尺度聚合的两条路线**:
   - Aggregation: 逐元素乘跨尺度交互 (更强但更重, 33.67M/232G)
   - ProgressiveAgg: 渐进跳跃融合 + LCAR (更轻且 FPS 最高, 16.43M/42.64G, 88FPS)

4. **ATAH 检测头**对定位精度有贡献 (可变形卷积自适应几何变换)，
   在 d-ATAH 消融实验中 mAP50-95=0.4997，可与上述 backbone/neck 模块组合。

## 三、小目标检测模块机制详解

### 3.1 DASI — 维度感知选择性集成 (红外小目标)

> **来源**: 红外小目标检测 (2024)
> **源码**: `ultralytics/nn/ExtraModules/attention/DASI.py`
> **YAML 用法**: `[-1, 1, DASI, [c2]]` (替换 Conv, 原位替换)

**核心机制**:
- `Bag` 子模块: 4 路并行空洞卷积 (dilation=2/4/6/8) → concat → 1x1 融合，
  构建超大感受野的金字塔，对小目标的微小特征做强响应。
- `DASI` 主模块: 跳跃连接 + 1x1 投影 + 尾部卷积融合 + BN + ReLU。

**对小目标的价值**: 红外小目标在特征图中仅占 1~2 像素，Bag 的大空洞率多尺度
并行能从周围上下文中聚合信息，增强稀疏响应。卫星图像中的军舰/战斗机
(相对 20K×5K 画幅属极小目标) 场景高度契合。

**实验结果**: mAP50-95=0.5232 (全榜第 1)，Recall=0.8094 (全榜最高)。

---

### 3.2 COI — Conv-One-Identity 三重残差卷积

> **来源**: HVPNet (RGB-T 显著目标检测)
> **源码**: `ultralytics/nn/ExtraModules/conv/COI.py`
> **YAML 用法**: `[-1, 1, COI, [c2, k, s]]` (替换 Conv)

**核心机制**: 三条并行路径相加后 GELU 激活:
1. Shortcut (恒等 + BN)
2. Depthwise Conv (通道独立, 保持空间)
3. 1x1 Conv (跨通道线性组合)

proj 同时负责通道对齐和 stride 降采样，内部三路无 stride。

**对小目标的价值**: 极轻量基础组件，深度可分离 + 残差连接，
适合嵌入 backbone 浅层 (P1/P2/P3) 替换 Conv，在不显著增加参数的前提下增强
浅层特征表达——浅层特征对小目标的低层纹理 (边缘/角点) 最关键。

**实验结果**: COI (100ep) mAP50-95=0.5088；COI-150 (150ep) 达 0.5216 (全榜第 2)。
说明 COI 对训练时长敏感，延长训练可继续涨点。

---

### 3.3 Aggregation — 多尺度密集注意力聚合

> **来源**: HVPNet (RGB-T 显著目标检测)
> **源码**: `ultralytics/nn/ExtraModules/neck/Aggregation.py`
> **YAML 用法**: `[[P5, P4, P3], 1, Aggregation, [c2]]` (from 为列表, 3 尺度)

**核心机制**:
1. 三尺度特征 P3/P4/P5 各自 1x1 投影到统一通道
2. 上采样后逐元素乘做跨尺度交互:
   - `x2_1 = upsample(x1) * x2`
   - `x3_1 = upsample²(x1) * upsample(x2) * x3`
3. 密集拼接 + 3x3 卷积 → 输出 P3 分辨率特征

**对小目标的价值**: 跨尺度逐元素乘能让深层语义指导浅层定位，
小目标在浅层 (P3) 有强响应但缺语义，在深层 (P5) 有语义但分辨率低，
逐元素乘是天然的小目标-大目标特征互补机制。

**实验结果**: mAP50-95=0.5058 (全榜第 4)，Precision=0.8659 (全榜最高之一)。
代价是参数量较大 (33.67M)，卫星超大图场景需权衡显存。

---

### 3.4 ProgressiveAgg — 渐进式特征聚合

> **来源**: ProGRess (PLF + LCAR) + HVPNet 密集融合
> **源码**: `ultralytics/nn/ExtraModules/neck/ProgressiveAgg.py`
> **YAML 用法**: `[[P3, P4, P5], 1, ProgressiveAgg, [c2, use_lcar]]`

**核心机制**:
1. PLF: 从深到浅渐进融合 (P5→P4→P3)，每个阶段深层上采样后与当前层 concat → 1x1 融合
2. LCAR: 每层融合后经轻量通道注意力 (1x1 conv + Sigmoid) + 残差连接
3. 所有层上采样到 P3 分辨率 → 拼接 → Bottleneck (1x1) 融合输出

**对小目标的价值**: 渐进式融合比一次性 concat 更平滑地传递多尺度信息，
LCAR 轻量通道注意力增强跨模态特征的通道选择性。对卫星图中不同尺度
(近景大目标 vs 远景小目标) 的自适应聚合效果好。

**实验结果**: mAP50-95=0.4998, **FPS=88.14 (全榜最高)**，
参数量仅 16.43M。是精度-速度均衡的最优 neck 选择。

---

### 3.5 ATAH — 自适应任务对齐检测头

> **来源**: CMFADet (Cross-Modality Feature Adaptive Interaction for RGB-IR Detection)
> **源码**: `ultralytics/nn/ExtraModules/head/ATAH.py`
> **YAML 用法**: `[[P3, P4, P5], 1, Detect_ATAH, [nc, hidc]]` (替换 Detect)

**核心机制** (三个对齐):
1. **任务对齐**: TaskawareFeatureModulator 用 GAP→降维→升维→Sigmoid 为
   分类/回归各自选择差异化特征 (分类关注"是什么", 回归关注"在哪里")
2. **回归对齐**: DyDCNv2 可变形卷积 (torchvision.ops.deform_conv2d, 无需 mmcv)
   + 空间偏移预测，自适应几何变换提升定位
3. **分类对齐**: 空间概率图 (cls_prob) sigmoid 约束，抑制虚检

**对小目标的价值**: 可变形卷积对小目标的形变/旋转敏感 (卫星图中军舰
朝向任意)，任务解耦让回归分支专注精确定位——小目标定位误差占比更大，
这是关键收益。原 mmcv 依赖已改写为纯 PyTorch + torchvision。

**实验结果**: d-ATAH 消融 mAP50-95=0.4997, mAP50=0.8615 (单模块第 5)。

---

### 3.6 SPDConv — 空间到深度卷积

> **来源**: GeoFuse-YOLO (SOEP: Small Object Enhance Pyramid)
> **源码**: `ultralytics/nn/ExtraModules/conv/SPDConv.py`
> **YAML 用法**: `[-1, 1, SPDConv, [c2]]` (替换 Conv/C3k2)

**核心机制**: 空间到深度转换将 H×W 分解为 4 个 (H/2)×(W/2) 子特征，
concat 后通道变 4C → 3x3 卷积 → 上采样恢复分辨率 → + 1x1 残差。
内置 P5 层 1x1 空间保护 (H<2 时直接返回残差)。

**对小目标的价值**: 不降分辨率就能扩大感受通道，保留小目标的
空间位置信息——卫星图中军舰可能只有十几像素，下采样会丢失。

---

### 3.7 C3_RFEM — 三分支共享权重空洞卷积 (TridentBlock)

> **来源**: Trident / Receptive Field Enhancement Module
> **源码**: `ultralytics/nn/ExtraModules/conv/TridentBlock.py` (类 C3_RFEM)
> **YAML 用法**: `[-1, 1, C3_RFEM, [c2, n, e]]` (替换 C3k2)

**核心机制**:
- TridentBlock: 共享权重 (1x1 降维 + 3x3 卷积) 以 dilation=1/2/3 执行三次，
  分别感受 small/middle/big 尺度，每路含残差。共享权重保证参数不随分支增长。
- RFEM: 堆叠 TridentBlock，输出 = BN(SiLU(x + sum(三路输出)))。
- C3_RFEM: C3 风格包装 (1x1 降维 → RFEM → 1x1 升维)。

**对小目标的价值**: 三种空洞率覆盖小/中/大目标，IR 小目标 (d=1 占优) 与
RGB 大目标 (d=3 占优) 自适应。文档明确标注"小目标检测最优位置"。

---

### 3.8 Conv_Coord — 坐标感知卷积

> **来源**: Coordinate Convolution (CoordConv)
> **源码**: `ultralytics/nn/ExtraModules/conv/CoordConv.py` (类 Conv_Coord)
> **YAML 用法**: `[-1, 1, Conv_Coord, [c2, k, s]]` (替换 Conv)

**核心机制**: AddCoords 在输入通道末尾拼接归一化 xy 坐标 (可选 +r 半径)，
使卷积核感知绝对空间位置，打破平移不变性。

**对小目标的价值**: 小目标定位依赖绝对位置先验；卫星超大图中目标位置
含强地理语义 (港口内的军舰 vs 跑道上的战斗机)，坐标通道能编码这类信息。

---

### 3.9 CARAFE — 内容感知特征重组上采样

> **论文**: ICCV2019, https://arxiv.org/abs/1905.02188
> **源码**: `ultralytics/nn/ExtraModules/neck/CARAFE.py` (类 CARAFE_Upsample)
> **YAML 用法**: `[-1, 1, CARAFE_Upsample, [None, 2, 'nearest']]` (替换 nn.Upsample)

**核心机制**: 两阶段——(1) 核预测: 压缩通道→编码→PixelShuffle→Softmax
为每个目标像素预测独立上采样核；(2) 特征重组: 最近邻上采样→unfold 取邻域→加权求和。

**对小目标的价值**: 比 nearest/bilinear 上采样保留更多小目标细节，
文档明确"小目标 AP +2.5~4.0%"。FPN 上采样阶段用 CARAFE 替换可提升小目标召回。

---

### 3.10 NWDLoss — Normalized Wasserstein Distance 小目标回归损失

> **论文**: https://arxiv.org/abs/2005.03572
> **源码**: `ultralytics/nn/ExtraModules/loss/NWDLoss.py`
> **用法**: 不通过 YAML，需手动挂载到 `ultralytics/utils/loss.py` (见源码底部集成指南)

**核心机制**: 将边界框建模为二维高斯分布，计算两高斯间的 Wasserstein-2
距离，再 exp(-sqrt(W²)/C) 归一化到 (0,1]。NWD Loss = 1 - NWD。

**对小目标的价值**: IoU 在两框不重叠时梯度为 0 (梯度消失)，小目标
仅几像素，稍微偏移就完全不重叠 → 训练停滞。NWD 对位置偏差的惩罚更平滑，
是小目标回归损失的标准替代方案。**卫星图小目标强烈推荐**。

**集成方式** (源码有详细文档):
- 在 `loss.py` 的 `BboxLoss.forward` 中将 `loss_iou` 替换为
  `(1-ratio)*(1-NWD).mean() + ratio*(1-IoU).mean()`，ratio∈[0.3,0.5]。
- 小目标密集场景 constant 建议增大到 20~30。

## 四、针对卫星小目标的组合推荐方案

基于上述分析，针对 20K×5K 卫星图军舰/战斗机小目标，推荐以下组合
(按"轻量→重型"梯度，供后续 Agent 选择):

### 方案 A: 轻量高速 (ProgressiveAgg 主导)
```
backbone: COI 替换浅层 Conv (P1/P2/P3)        ← 轻量增强浅层
neck:    ProgressiveAgg 替换 FPN 融合         ← FPS 88, 精度-速度最优
head:    Detect (标准) 或 ATAH                 ← 视显存而定
loss:    NWD + IoU 混合                        ← 小目标回归
```
**预期**: mAP50-95 ≈ 0.50~0.52, FPS 高, 显存友好 (适合 4GB 卡)。

### 方案 B: 高精度 (DASI + Aggregation 主导)
```
backbone: DASI 替换浅层 Conv + C3_RFEM 替换中层 C3k2
neck:    Aggregation 跨尺度聚合
head:    ATAH 任务对齐
loss:    NWD + IoU 混合
```
**预期**: mAP50-95 ≈ 0.52+, 精度最高, 但显存压力大 (需切片训练)。

### 方案 C: 论文级系统方案 (三级感知 + 全链路)
参考 `docs/实验方案.md` 的 "组合 D: HyperDet" — 多粒度感知框架:
```
Conv_Coord (位置) → C3_RFEM (尺度) → ATAH (任务)
+ DASI (红外小目标) + CARAFE (上采样) + NWD (损失)
```
**卖点**: "三级感知"系统框架, 全链路小目标增强, 可独立成文。

### 卫星超大图 (20K×5K) 的特殊注意事项

1. **切片训练 (Tiling)**: 20K×5K 无法直接输入，需切成 640/1280 子图训练，
   推理时滑窗拼接。FLIR 数据集是 640 通用场景，迁移到卫星图需重做切片流程。
2. **P2 层利用**: 标准 YOLO neck 只到 P3 (stride 8)。卫星图小目标可能
   需引入 P2 (stride 4) 检测头，SPDConv + C3_RFEM 在 P2 层价值最大。
3. **NWD constant 调参**: 卫星图小目标框可能 <10px，constant 需调小
   (源码建议密集小目标场景 20~30，但卫星极小目标可能需 <12.8，需实验)。
4. **显存**: Aggregation (232G FLOPs) 在 4GB 卡上需 batch=1~2；
   ProgressiveAgg (42.64G) 更友好。DASI (142G) 也偏重。
5. **数据集**: 当前 val_results 基于 FLIR (可见光+红外双模态)。
   卫星图若是单模态 RGB，则 SilenceChannel/双分支架构需调整；
   若有 SAR/红外卫星图配对，则 RGBT 架构直接适用。

### 5.3 注册流程 (新模块)
1. 模块 .py 放 `ultralytics/nn/ExtraModules/{子目录}/`
2. `__init__.py` 追加 `from .子目录.模块名 import *` (放在 "YOLO 包装器" 行前)
3. `tasks.py` 注册:
   - 单输入模块 → `base_modules` 集合 (约 1080 行)
   - 多输入/融合模块 → `base_modules` + `parse_model` 多输入分支 (约 1121 行)
   - 检测头 → `parse_model` 检测头分支 (约 1125 行) + isinstance 检查 (约 296/362 行)
4. 创建 YAML → `python -c "from ultralytics import YOLO; YOLO('YAML路径').info()"` 验证
5. 冒烟测试 → **先询问用户**再跑 2 epochs

### 5.4 关键避坑点
- **BatchNorm + 空间 1x1 + bs=1 崩溃**: YOLO 用 `torch.zeros(1,ch,32,32)` 推断
  stride，P5 层空间 1x1 时 BN 报错 → 全部门控/归一化路径用 `nn.GroupNorm(1, ch)`。
  (ATAH.py 已用 Conv_GN + GroupNorm(16)，可参考)
- **EMA 不兼容 register_buffer**: 用普通 Python dict 缓存 (参考 vHeat_Fusion)。
- **timm 版本**: `timm.models.layers` 已废弃，改 `timm.layers`。
- **c1 多输入**: parse_model 会把 c1 转 list，`__init__` 须处理 `isinstance(c1, (list,tuple))`。
- **环境**: 必须用 `D:\Anaconda\envs\torch310\python.exe`，不要用系统 python。
