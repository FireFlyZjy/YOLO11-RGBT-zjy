### ICAFusion 核心架构

```
   RGB Feature (H×W×C)              IR Feature (H×W×C)
         |                                |
   AdaptivePool2d                  AdaptivePool2d
   (avg+max 可学习加权)            (avg+max 可学习加权)
         |                                |
   位置编码 (sin-cos)              位置编码 (sin-cos)
         |                                |
   ┌─────────────────────────────────────────┐
   │       CrossTransformerBlock × N         │
   │  ┌──────────────────────────────────┐   │
   │  │   CrossAttention                 │   │
   │  │   IR_Q × VIS_K → VIS attention   │   │
   │  │   VIS_Q × IR_K → IR attention    │   │
   │  └──────────────────────────────────┘   │
   │  + MLP (GELU) + 8个LearnableCoefficient │
   └─────────────────────────────────────────┘
         |                                |
   Upsample + Skip Connect        Upsample + Skip Connect
         |                                |
   Concat(2C) → 1×1Conv → C  (拼接投影)
         |
    融合特征输出
```

### CMFADet vs ICAFusion 对比

| 维度 | CMFADet (CIFusion) | ICAFusion |
|------|-------------------|-----------|
| 融合机制 | 交叉交换+通道注意力 (CNN) | 交叉注意力+MLP (Transformer) |
| 参数量 | 轻量 (~0.1M) | 较重 (含MultiheadAttention) |
| 专用模块 | SFEM(RGB) + IRAFAB(IR) + DEConv | 无 |
| 位置编码 | 无 | 可学习sin-cos 2D |
| 适用场景 | 轻量级双模态交互 | 全局跨模态上下文建模 |

> 移植依赖: torchvision.ops.deform_conv2d (纯 PyTorch, 无需 mmcv)

**改动说明**:

| 维度 | 原版 CMFADet ATAH | 移植版 |
|------|------------------|--------|
| 可变形卷积 | mmcv.ModulatedDeformConv2d | torchvision.ops.deform_conv2d |
| 归一化层 | mmcv.build_norm_layer | nn.GroupNorm(16, out_channels) |
| 输入对齐 | 无 (依赖YAML统一通道) | 新增1x1投影层, P3/P4/P5→hidc |
| 依赖 | mmcv-full | 纯 torch + torchvision |

**核心架构**:

```
   P3(31)  P4(34)  P5(37)
     |       |       |
  1x1Proj 1x1Proj 1x1Proj  ← 通道对齐到 hidc
     |       |       |
   share_conv (hidc → hidc//2 → hidc//2)  ← 共享特征提取
     |       |       |
   ┌─cls_branch(TaskAwareFeatureMod)  ← 分类: 全局池化→降维→Sigmoid门控
   └─reg_branch(TaskAwareFeatureMod)  ← 回归: 同上
              |
         DyDCNv2 (可变形卷积 v2)     ← offset+mask 空间对齐
              |
         cv2(reg_feat×scale) + cv3(cls_feat×cls_prob)
              |
         [B, 4*reg_max+nc, H, W]     ← 输出
```

**代码文件修改**:

| 文件 | 改动 |
|------|------|
| `ultralytics/nn/ExtraModules/head/ATAH.py` | **新建**，~170行。包含 `Scale`, `Conv_GN`, `TaskawareFeatureModulator`, `DyDCNv2`, `Detect_ATAH` 五个类 |
| `ultralytics/nn/ExtraModules/head/__init__.py` | **新建**，`from .ATAH import *` |
| `ultralytics/nn/ExtraModules/__init__.py` | 第32行，新增 `from .head import *` |
| `ultralytics/nn/tasks.py` | 第1124行新增 `Detect_ATAH` 特殊处理 (args.append) ; 第296/362行 isinstance 检查追加 `Detect_ATAH` |

**Detect_ATAH vs Detect 对比**:

| 维度 | Detect | Detect_ATAH |
|------|--------|-------------|
| 参数 | `Detect, [nc]` | `Detect_ATAH, [nc, hidc]` |
| 分支 | 独立 conv per layer | 共享 share_conv + 任务感知调制 |
| 空间对齐 | 无 | DyDCNv2 可变形卷积 |
