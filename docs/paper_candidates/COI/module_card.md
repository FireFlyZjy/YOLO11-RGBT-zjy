# COI — Conv-One-Identity 三重残差卷积

## 基本信息

| 项目 | 内容 |
|------|------|
| **模块名** | COI (Conv-One-Identity) |
| **类别** | conv（卷积变体，替换 Conv） |
| **来源论文** | HVPNet (RGB-T 显著目标检测) |
| **来源仓库** | exps/HVPNet-main |
| **源码** | `ultralytics/nn/ExtraModules/conv/COI.py` |
| **YAML 用法** | `[-1, 1, COI, [c2, k, s]]`（k=卷积核大小, s=步幅） |
| **参数签名** | `__init__(self, c1, c2, k=3, s=1)` |

## 核心机制

COI 用三条并行路径替代单个卷积，三路输出相加后经 GELU 激活：

1. **Shortcut 路径** — 恒等映射 + BatchNorm，保留原始输入信息
2. **Depthwise Conv 路径** — 深度可分离卷积（groups=c2），保持通道独立的空间特征
3. **1x1 Conv 路径** — 逐点卷积，实现跨通道线性组合

`proj` 层（1x1 Conv）统一负责通道对齐和空间降采样（当 `c1 != c2` 或 `s > 1` 时），内部三条路径均无 stride。

### 伪代码

```
input x
x = proj(x)                        # 1x1 通道对齐 + stride 降采样
shortcut = BN(x)                   # 路径1: 恒等
x_dw = BN(DWConv(x))               # 路径2: 深度可分离
x_1x1 = BN(Conv1x1(x))            # 路径3: 跨通道
output = GELU(shortcut + x_dw + x_1x1)
```

## 网络结构

```
        ┌── BN ─────────────── shortcut
x ──proj┤
        ├── DWConv(3x3) ── BN ── x_dw
        └── Conv(1x1) ── BN ── x_1x1
                                    ↓
              GELU(shortcut + x_dw + x_1x1) ── output
```

## 插入策略

- **替换位置**: RGB 和 IR 分支的浅层 Conv（层 2/3/5 和 12/13/15）
- **原因**: 浅层特征对小目标的低层纹理（边缘/角点）最关键，COI 的三重残差在不显著增加参数的前提下增强浅层特征表达
- **原位替换**: 不改变层号，避免对 neck/head 引用的影响

## 创新点与局限

**优点**:
- 极轻量（14.96M params），三重残差连接增强特征表达
- 对训练时长敏感，延长训练可继续涨点（100ep→150ep mAP50-95 +0.0128）
- 浅层嵌入，适合小目标检测的底层纹理增强

**局限**:
- FLOPs (108.96G) 较基线 (34.41G) 显著增加，因替换了 6 个 Conv
- FPS 下降明显（12.84 vs 基线 52.67），不适合对速度敏感的场景
