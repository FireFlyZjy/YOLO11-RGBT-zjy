## 二、修改详情

### 2.1 SPPF 类

**位置**：`ultralytics/nn/modules/block.py` 第 182 行附近

**改动内容**：

| 项目 | 旧代码 (v11) | 新代码 (v11to26 / yolo26) |
|------|-------------|--------------------------|
| 参数 | `(c1, c2, k=5)` | `(c1, c2, k=5, n=3, shortcut=False)` |
| cv1 | `Conv(c1, c_, 1, 1)` | `Conv(c1, c_, 1, 1, act=False)` — 无激活函数 |
| cv2 | `Conv(c_ * 4, c2, 1, 1)` | `Conv(c_ * (n + 1), c2, 1, 1)` — 动态通道数 |
| 池化次数 | 固定 3 次 | 由 `n` 参数控制 |
| shortcut | 无 | `self.add = shortcut and c1 == c2` |
| 类型注解 | 无 | 完整类型注解 |

**代码结构**（旧代码被 `'''` 注释保留，新代码直接生效）：

```python
'''
class SPPF(nn.Module):  # ===== yolo26 新代码替换此处 =====
    ...旧代码...
'''  # ===== yolo26 新代码: 支持 n/shortcut 参数 =====

class SPPF(nn.Module):
    ...新代码...
```

**YAML 兼容性**：新 SPPF 兼容旧 YAML 写法 `SPPF, [c2, k]`，也支持新写法 `SPPF, [c2, k, n, shortcut]`。

### 2.2 C3k2 类

**位置**：`ultralytics/nn/modules/block.py`（在原定义之后）

**改动内容**：

| 项目 | 旧代码 (v11) | 新代码 (v11to26 / yolo26) |
|------|-------------|--------------------------|
| 参数 | `(c1, c2, n=1, c3k=False, e=0.5, g=1, shortcut=True)` | `(c1, c2, n=1, c3k=False, e=0.5, attn=False, g=1, shortcut=True)` |
| 新增 | — | `attn: bool = False` 参数 |
| 内部模块 | `C3k` 或 `Bottleneck` | `C3k`、`Bottleneck`、或 `Bottleneck + PSABlock` 序列 |
| 类型注解 | 无 | 完整类型注解 |

`attn=True` 时，每个 block 变为 `Bottleneck → PSABlock` 序列，相当于在 C3k2 中嵌入自注意力。

**代码结构**：

```python
'''
class C3k2(C2f):  # ===== yolo26 新代码替换此处 =====
    ...旧代码...
'''  # ===== yolo26 新代码: 新增 attn 参数, 支持 PSABlock 注意力 =====

class C3k2(C2f):
    ...新代码...
```

**YAML 用法**：
```yaml
# 不带注意力（同旧版行为）
- [-1, 2, C3k2, [256, False, 0.25]]

# 带注意力
- [-1, 2, C3k2, [256, False, 0.25, True]]  # attn=True
```
