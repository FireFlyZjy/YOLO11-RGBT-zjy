## 2026-05-13

### 新增11个注意力模块

在双模态YOLO中融合架构中，于P3/P4/P5三个尺度的Concat融合之后插入注意力模块，用于对融合特征做跨通道/空间重标定。

| 模块 | 论文 | 类型 | 参数量 |
|------|------|------|--------|
| **Att_CBAM** | CBAM (ECCV 2018) | 通道+空间 | +0.05M |
| **Att_Coord** | Coordinate Attention (CVPR 2021) | 通道+坐标编码 | +0.03M |
| **Att_SimAM** | SimAM (ICML 2021) | 无参数3D | +0.00M |
| **Att_CPCA** | CPCA (2023) | 通道先验+多尺度空间 | +0.70M |
| **Att_EMA** | EMA (2023) | 分组交叉空间 | +0.06M |
| **Att_ECA** | ECA-Net (CVPR 2020) | 1D卷积通道 | +0.00M |
| **Att_Shuffle** | ShuffleAttention (2021) | 分组通道+空间 | +0.00M |
| **Att_LSKA** | LSKA (2023) | 大核可分离空间 | +0.41M |
| **Att_Triplet** | Triplet Attention (2020) | 跨维度空间 | +0.00M |
| **Att_GAM** | GAM (2021) | 全局注意力 | +9.83M |
| **Att_ELA** | ELA (2024) | 方向局部注意力 | +0.39M |

**插入策略**: 在双模态Concat融合之后(P3/P4/P5)，SPPF之前。注意力模块学习两种模态特征的互补性权重，抑制融合噪声。

**改进动机**: 双模态特征直接Concat存在信息冗余和模态冲突，注意力机制能自适应地筛选融合后的有效特征，在不同尺度上独立学习可见光-红外的重要性分布。

### 先前已集成的模块（7个）

| 模块 | 来源 | 核心思想 |
|------|------|----------|
| **ACBlock** | ACNet (ICCV 2019) | 非对称卷积，训练时3×3→3×3+3×1+1×3，推理BN融合零开销 |
| **BlazeBlock** | BlazeFace (CVPR 2019) | dw+pw-linear无激活瓶颈，轻量化IR分支 |
| **ASPP_Branch** | DeepLab | 不同膨胀率深度可分离卷积并行，多尺度上下文 |
| **GCBlock** | Context Gating (2017) | 跨通道特征重标定，可学习权重矩阵+BN+sigmoid |
| **C2f_DCN** | DCNv2 (CVPR 2019) | 可变形卷积v2，自适应采样+调制掩码 |
| **SEAttention** | SENet (CVPR 2018) | 全局池化→FC→ReLU→FC→Sigmoid通道重标定 |
| **CSP_ATT** | CSPNet + SE | SPPF替代方案，CSP+多尺度MaxPool+SE |

### 新增AIFI (RT-DETR Transformer自注意力)

从 `yolo-improve` 目录中筛选，将 RT-DETR 的 AIFI 模块集成到双模态YOLO中，替代 SPPF 层。

| 模块 | 论文 | 类型 | 参数量 |
|------|------|------|--------|
| **Att_AIFI** | RT-DETR (2023) | Transformer自注意力+2D位置编码 | +2.33M |

**改进动机**: SPPF 仅通过固定大小的池化核捕获上下文，无法建模全局长程依赖。AIFI 使用多头自注意力+2D sin-cos位置编码，在 P5 最深特征图上提供全局上下文建模能力，对双模态融合后的特征做跨空间位置的信息交互。

**插入位置**: P5 Concat融合之后，C2PSA之前（替代SPPF），其余结构不变。

**验证结果**: Att_AIFI 模型成功实例化（17.34M params）并通过 forward pass。

## 2026-05-19

### 新增CMFADet模块 (3个YAML配置, 4个底层模块)

从 CMFADet (RGB-Infrared 航空目标检测论文) 中整合了4个互补模块。

| 模块 | 论文 | 类型 | 参数量 |
|------|------|------|--------|
| **Att_CIFusion** | CMFADet | 跨模态交叉交换通道注意力融合 | +5.7M |
| **Att_SFEM** | CMFADet | 空间-频率增强 (FFT频域+Scharr边缘), RGB专用 | +0.3M |
| **Att_IRAFAB** | CMFADet | 自适应多核深度卷积+门控线性单元, IR专用 | +0.3M |
| **Conv_DE** | DEConv | 5路边缘感知重参数化卷积, 推理零开销 | +0M |

**核心创新**:
- **CIFusion**: 不是简单Concat或加权融合。它做通道注意力门控后**交叉交换**RGB和IR的特征——RGB的注意力特征放到IR通道位置，IR的放到RGB位置，实现双向信息传递
- **SFEM + IR_AFAB**: 首次在YOLO中实现**非对称骨干**——RGB分支用频域+边缘分析，IR分支用自适应多核深度卷积
- **Conv_DE**: 训练时5种边缘差分卷积并行，推理时融合为1个3×3卷积，零推理开销

**YAML配置** (2026-05-19/):
| 文件 | 内容 |
|------|------|
| `CIFusion.yaml` | Concat → CIFusion (交叉交换融合) |
| `SFEM_IRAFAB.yaml` | RGB: SFEM + IR: IRAFAB (非对称骨干) |
| `CMFADet.yaml` | SFEM + IRAFAB + CIFusion (全组合) |

**验证结果**: 全部通过模型实例化和forward pass

### 新增ICAFusion模块 (1个YAML配置, 核心: TransformerFusionBlock)

从 ICAFusion (Iterative Cross-Attention Guided Feature Fusion, Pattern Recognition 2023) 中集成其核心跨模态Transformer融合模块。

| 模块 | 论文 | 类型 | 参数量 |
|------|------|------|--------|
| **Att_ICAFusion** | ICAFusion (PR 2023) | 迭代交叉注意力Transformer融合 | +16.6M (vs baseline Concat) |

**核心创新**:
- **双交叉注意力**: RGB和IR各用独立QKV投影，计算交叉注意力矩阵（IR query × VIS key / VIS query × IR key），实现双向信息传递
- **可学习系数残差**: 8个可学习系数控制注意力输出和MLP的残差比例，提供细粒度梯度调节
- **位置编码**: 可学习的1D位置编码，让Transformer感知特征图空间结构
- **自适应池化**: avg+max双池化可学习加权融合，将特征下采样到固定网格(16×16)降低计算量

**与CIFusion的差异**: CIFusion是轻量级通道注意力交叉交换(0.6M)，ICAFusion是完整的Transformer跨模态融合(16.6M)。前者更轻量适合浅层，后者全局交互能力更强适合深层。

**YAML配置** (2026-05-19/):
| 文件 | 内容 |
|------|------|
| `yolo26-RGBT-midfusion-ICAFusion.yaml` | Concat → Att_ICAFusion (迭代交叉注意力Transformer融合) |

**验证结果**: 模型成功实例化(58.82M params)并通过forward pass

## 2026-05-26

### 新增 ATAH 检测头 (Adaptive Task-aware Alignment Head)

从 CMFADet 中移植 ATAH 模块，替换标准 Detect 检测头。

| 模块 | 论文 | 类型 | 参数量 |
|------|------|------|--------|
| **Detect_ATAH** | CMFADet | 任务感知对齐检测头 | +3.2M (vs standard Detect) |

**核心创新**:
- **任务感知特征调制 (TaskAwareFeatureModulator)**: 全局平均池化→降维→Sigmoid门控，分离分类和回归分支的特征偏好
- **回归对齐 (DyDCNv2)**: 可变形卷积v2根据特征本身学习采样偏移，动态校正回归空间位置
- **分类对齐 (空间概率图)**: 学习空间注意力概率图约束分类输出，抑制背景噪声
- **共享特征提取**: P3/P4/P5 共享 share_conv 而非独立卷积分支，减少参数量
- **1×1 通道投影**: 将 P3/P4/P5 不同通道统一对齐到 hidc，无需修改 Neck

**移植改动 vs 原版 CMFADet**:
- `mmcv.ModulatedDeformConv2d` → `torchvision.ops.deform_conv2d`（消除mmcv依赖）
- 新增 1×1 投影层（原版依赖YAML统一通道，本项目Neck通道不一致）

**插入位置**: 替换 YOLO 最后一层 Detect，层号不变。P3/P4/P5 输入经 1×1 投影对齐后进入 ATAH。

## 2026-06-04

### 从 vHeat-main (CVPR 2025) 提取 2 个新模块

基于原论文 `vHeat: Building Vision Models upon Heat Conduction` 的完整源码，提取并实现了两个模块：

#### 1. vHeat_Block（完整热传导块）

| 属性 | 内容 |
|------|------|
| **模块名** | `vHeat_Block` |
| **来源** | vHeat (CVPR 2025) — `classification/models/vHeat.py` 中的 `HeatBlock` |
| **类型** | 频域 Transformer-style block (替换 SPPF/C3k2/C2PSA) |
| **参数量** | +3.55M (P5 位置, scale=s, 含 dwconv+门控+MLP) |
| **核心机制** | Pre-Norm → HCO(DCT→自适应k预测→热扩散衰减→IDCT→SiLU门控→残差) → DropPath → Norm → MLP(1×1Conv扩张4×→GELU→压缩) → DropPath |
| **vs 已有 vHeat** | 我们的 vHeat 仅含 HCO 核心算子；vHeat_Block 是原论文完整结构，增加 dwconv 预处理、SiLU 门控、MLP/FFN、DropPath 正则化 |

**对 RGBT 的价值**:
- dwconv 预处理捕获局部邻域上下文（对红外噪声预平滑）
- SiLU 门控机制选择性传递频率信息
- MLP/FFN 提供通道混合增强跨模态信息交互
- DropPath 正则化对抗红外模态过拟合
- O(N^1.5) 复杂度，低于 Self-Attention 的 O(N²)

**插入策略**: 替换 SPPF（层24），P5 融合特征进入颈部前做全局频域建模

**验证结果**: 导入通过 / forward pass通过 / YAML模型构建通过 / 训练2 epochs完成

#### 2. vHeat_Fusion（跨模态热传导融合）⭐ 论文级创新

| 属性 | 内容 |
|------|------|
| **模块名** | `vHeat_Fusion` |
| **来源** | vHeat (CVPR 2025) 热传导原理的 RGB-T 扩展创新 |
| **类型** | 频域跨模态融合 (替换 Concat) |
| **参数量** | +1.05M (每个融合点, c2=512) |
| **核心机制** | RGB/IR分别→DCT→模态特定k预测(k_rgb小保留细节/k_ir大抑制噪声)→热扩散衰减→跨模态频率门控→频域加权融合→IDCT→空域融合特征 |

**对 RGBT 的价值**:
- **频域天然解耦**: RGB 高频纹理 vs IR 低频热辐射在 DCT 域自然分离
- **自适应去噪**: IR 噪声在频域表现为高频伪影→大 k_ir 自动衰减
- **细节保留**: RGB 纹理在高频→小 k_rgb 保留
