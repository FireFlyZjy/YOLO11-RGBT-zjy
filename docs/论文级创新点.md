## 2026-06-04

### vHeat_Fusion: 基于热传导方程的跨模态频域融合

> **创新等级**: ⭐⭐⭐ (论文级 — 首次将热传导原理引入 RGB-T 融合)
> **来源论文**: vHeat (CVPR 2025) — 热传导算子 HCO 的跨模态扩展
> **mAP50**: 0.8567（未达 0.865 阈值，因创新性保留）

---

#### 一、问题定义

**RGB-T 检测的核心挑战**: 可见光(RGB)和红外(IR)是两种物理特性截然不同的模态：

| 维度 | RGB | IR |
|------|-----|-----|
| 物理原理 | 反射可见光 | 热辐射 |
| 高频分量 | 纹理/边缘丰富 | 噪声占主导 |
| 低频分量 | 光照敏感 | 稳定的热轮廓 |
| 频域特征 | 全频段信息 | 能量集中在低频 |

**现有融合方法的局限**:
1. **Concat 融合**: 简单拼接，无模态交互，信息冗余
2. **Cross-Attention 融合**: O(N²) 复杂度，计算量大
3. **门控融合**: 仅在通道维度加权，忽略频域差异

**关键洞察**: RGB 和 IR 在**频域**天然互补——RGB 的高频纹理 + IR 的低频热辐射 = 完整场景表征。但现有方法都在**空域**融合，无法显式利用这种频域互补性。

---

#### 二、核心创新: 热传导方程驱动的频域融合

##### 2.1 物理直觉

热传导方程描述了热量如何随时间在介质中扩散：

```
∂u/∂t = k · (∂²u/∂x² + ∂²u/∂y²)

频域解: U(ω, t) = U₀(ω) · exp(-k · t · |ω|²)
```

**物理解释**: 高频分量（大 |ω|）随时间指数衰减，衰减速度由热扩散系数 k 控制。

**RGB-T 映射**:
- RGB 模态 → 小 k_rgb → 缓慢衰减 → 保留高频纹理
- IR 模态 → 大 k_ir → 快速衰减 → 抑制高频噪声
- 热扩散成为**自适应频域滤波器**，对不同模态自动调节截止频率

##### 2.2 架构设计

```
                    ┌─────────────────────────────────┐
                    │        vHeat_Fusion              │
                    │                                   │
  RGB ──→ Proj ──→ DCT ──→ k_rgb预测 ──→ 衰减_rgb ──┐ │
                    │                                  ├─→ 跨模态 ──→ IDCT ──→ Out
  IR  ──→ Proj ──→ DCT ──→ k_ir 预测 ──→ 衰减_ir ──┘ │    门控
                    │                                   │
                    └─────────────────────────────────┘

详细流程:
  Step 1: RGB/IR 分别 1×1 投影到统一通道数 c2
  Step 2: 2D DCT 将空域特征变换到频域 (矩阵乘法, O(N^1.5))
  Step 3: 自适应预测模态特定热扩散系数 k_rgb, k_ir ∈ (0, 1)
          - k 从 GAP 特征通过 FC+ReLU+Sigmoid 预测
          - 内容自适应: 不同图像/通道有不同的 k
  Step 4: 频域热扩散衰减
          - dct_rgb' = dct_rgb · exp(-k_rgb · t · freq²)
          - dct_ir'  = dct_ir  · exp(-k_ir  · t · freq²)
  Step 5: 跨模态频率门控
          - 拼接两模态频域特征 → GAP → FC → Sigmoid → 拆分为 gate_rgb, gate_ir
          - dct_fused = gate_rgb · dct_rgb' + gate_ir · dct_ir'
          - 门控在频域操作，决定每个频率分量来自哪个模态
  Step 6: 2D IDCT 恢复空域 + 输出投影 + BN + SiLU
```

##### 2.3 核心算子复杂度

| 算子 | 复杂度 | 对比 |
|------|--------|------|
| vHeat_Fusion (DCT/IDCT) | O(C · N^1.5) | N=特征图边长 |
| Self/Cross-Attention | O(C · N²) | — |
| 加速比 (N=20, P5) | ~4.5× | 20² / 20^1.5 ≈ 89 / 20 ≈ 4.5× |

---

#### 三、为什么这是论文级创新

##### 3.1 首次实现
1. **首次**将热传导方程从单模态 backbone 扩展到**跨模态融合**
2. **首次**在 DCT 频域进行 RGB-T 自适应融合（而非空域或通道域）
3. **首次**利用热扩散系数的物理意义实现模态特定的频率选择性

##### 3.2 与现有方法的关系

| 方法 | 融合域 | 模态交互 | 复杂度 |
|------|--------|----------|--------|
| Concat (基线) | 通道域 | 无 | O(1) |
| CIFusion (通道注意力融合) | 通道域 | 通道加权 | O(C²) |
| ICAFusion (交叉注意力) | 空域 | 全局 | O(N²) |
| AFF (注意力特征融合) | 多尺度 | 局部 | O(N) |
| **vHeat_Fusion (本方法)** | **频域** | **频率门控** | **O(N^1.5)** |

vHeat_Fusion 是**唯一在频域工作**的融合方法，填补了 RGB-T 融合在频域的空白。

##### 3.3 物理可解释性
- k_rgb 小 → RGB 高频保留 → 纹理/边缘信息保留 → 可解释为"纹理保留系数"
- k_ir 大 → IR 高频抑制 → 热噪声去除 → 可解释为"噪声抑制系数"
- 频率门控在 DCT 域 → 显式选择每个频率分量的模态来源 → 可解释为"频谱分配"

---

## 2026-06-20

### FCMMFusion: 跨分支交叉门控融合

> **创新等级**: ⭐⭐ (架构创新 — 将 FCM 的 Cross-Gating 机制改造为 RGB-T 双模态融合)
> **来源**: FCM-main (FCM/FCM_1/FCM_2/FCM_3 系列模块的思想) 改造
> **mAP50**: 0.8602（未达 0.865 阈值，因创新性保留）

#### 一、问题定义

RGB-T 检测中，双模态融合的核心挑战是如何让两种模态**互相增强**而非简单叠加：
- Concat: 通道拼接，无模态交互
- Add: 直接相加，假设两模态贡献相等
- CIFusion: 通道域交叉交换，但不区分空间和通道维度

需要一种机制，能**分维度**地让一种模态去门控另一种模态：
- 空间维度: IR 的热辐射分布告诉 RGB "哪些区域重要"
- 通道维度: RGB 的纹理特征告诉 IR "哪些通道有效"

#### 二、核心创新机制

**FCMMFusion** 的双路交叉门控设计：

```
vis ──→ 1x1 Proj ──→ vis_feat ──→ × SpatialGate(ir_feat) ──→ vis_gated ──┐
ir  ──→ 1x1 Proj ──→ ir_feat  ──→ × ChannelGate(vis_feat) ──→ ir_gated ──┤──→ Fusion → output
```

1. **空间门控 (SpatialGate)**: 对 ir_feat 做 Conv1x1→GroupNorm→SiLU→Conv1x1→Sigmoid，生成空间注意力掩码，作用于 vis_feat。IR 的热辐射区域自然高亮，帮助 RGB 聚焦目标。
2. **通道门控 (ChannelGate)**: 对 vis_feat 做 GAP→Conv1x1→GroupNorm→SiLU→Conv1x1→Sigmoid，生成通道注意力权重，作用于 ir_feat。RGB 的纹理信息帮助 IR 选择有效通道。

**设计选择**:
- GroupNorm 替代 BatchNorm: 兼容 P5 层空间 1x1 + batch_size=1 的模型初始化场景
- ratio=4 中间通道压缩: 平衡参数量和表达能力
- 无额外位置编码: 空间门控本身隐式编码了空间位置信息

#### 三、与现有方法对比

| 方法 | 融合域 | 门控维度 | 参数量 | 复杂度 |
|------|--------|----------|--------|--------|
| Concat | 通道域 | 无 | 0 | O(1) |
| CIFusion | 通道域 | 通道(交叉交换) | +5.7M | O(C²) |
| vHeat_Fusion | 频域 | 频率(热传导衰减) | +6.3M | O(N^1.5) |
| **FCMMFusion** | 空域 | 空间+通道(双路交叉) | +3.5M | O(C·H·W) |

**独特性**: FCMMFusion 是唯一在空域同时做空间门控和通道门控的跨模态融合模块，且两路门控信息来源相反（空间门控来自 IR，通道门控来自 RGB）。

#### 四、消融实验建议

1. **门控组合消融**: 仅空间门控 vs 仅通道门控 vs 双路门控
2. **门控来源消融**: 空间门控来自 vis vs 来自 ir
3. **与 CIFusion 级联**: FCMMFusion + CIFusion vs 独立使用
4. **与 vHeat_Fusion 互补**: FCMMFusion(空域) + vHeat_Fusion(频域) 级联
5. **ratio 参数**: ratio=2/4/8 对参数量和性能的影响

#### 五、实现验证

|------|------|
| **模块文件** | `ultralytics/nn/ExtraModules/fusion/FCMMFusion.py` |
| **YAML配置** | `ultralytics/cfg/models/26-RGBT/2026-06-20/fusion/yolo26-RGBT-midfusion-FCMMFusion.yaml` |

## 2026-07-13

### ProgressiveAgg: PLF+LCAR 渐进式检测头

> **mAP50**: 0.8654 (> 0.865 ✓)
> 将 rmae ProGRess 分割头的 **渐进跳跃融合(PLF) + 轻量通道注意力残差(LCAR)**
> 首次迁移到 YOLO 检测 Neck。

**核心创新**:
1. PLF: 从检测最深尺度(P5)到最浅尺度(P3)逐步融合, 每层将深层上采样后与当前层拼接
2. LCAR: 1×1 卷积+Sigmoid 门控 → 逐通道加权 → 残差连接
3. Bottleneck: 所有尺度上采样到 P3 分辨率 → 拼接 → 1×1 融合 → 输出

**架构设计**:

```
         ProgressiveAgg 渐进式多尺度聚合

  输入: [P3, P4, P5] (分辨率从大到小)

  Step 1: 投影对齐
  ────────────────────────────────────────
  P3 ──→ 1×1 Conv ──→ P3'  (统一通道 c2)
  P4 ──→ 1×1 Conv ──→ P4'
  P5 ──→ 1×1 Conv ──→ P5'

  Step 2: PLF 渐进跳跃融合 (从深到浅)
  ────────────────────────────────────────

  P5' ─────────────────────────┐
                                │ Upsample
  P4' ──→ Concat(P4', P5'↑) ──→ 1×1 ──→ P4''
                                │
                                │ Upsample
  P3' ──→ Concat(P3', P4''↑) ─→ 1×1 ──→ P3''

  Step 3: LCAR 轻量通道注意力残差
  ────────────────────────────────────────

  P3'' ──→ 1×1 Conv → Sigmoid → × P3'' ──→ + P3'' ──→ P3'''
  P4'' ──→ 1×1 Conv → Sigmoid → × P4'' ──→ + P4'' ──→ P4'''
  P5'  ──→ 1×1 Conv → Sigmoid → × P5'  ──→ + P5'  ──→ P5'''

  Step 4: Bottleneck 融合
  ────────────────────────────────────────

  P3'''    P4'''    P5'''
    │  Upsample  Upsample
    │    │        │
    └────┴────────┘
         │ Concat
    ┌────┴────┐
    │ 1×1+BN  │
    │ +GELU   │
    └────┬────┘
         │
       output
```

## 2026-08-02

### COI-DASI-Asymmetric: 模态特异性非对称 backbone

> **创新等级**: ⭐⭐ (范式创新 — 首次用 mAP50>0.865 模块组合实现 RGB-T 非对称骨干)
> **改装自**: COI (Conv-One-Identity, 来源: HVPNet RGB-T 显著目标检测, mAP50=0.8693) + DASI (Dimension-Aware Selective Integration, 来源: 红外小目标检测 2024, mAP50=0.886)
> **mAP50**: 待训练（源模块: COI=0.8693, DASI=0.886）
> **前置改动**: `DASI.py` 添加 `s=1` stride 参数（向后兼容现有 YAML）

**核心创新**:
- **模态特异性非对称设计**: RGB 分支用 COI（三重残差: shortcut+DWConv+1×1），IR 分支用 DASI（4级空洞卷积 dilation=2/4/6/8 并行选择集成）
- **物理动机**: RGB 纹理/边缘丰富 → COI 通道+空间双增强保留细节; IR 小目标热响应稀疏 → DASI 大感受野捕获上下文
- **stride 对齐**: 两分支 stride 一致（层 2/12 stride=2, 层 3/5/13/15 空间分辨率对齐），Concat 无冲突
- **与旧条目 SFEM+IRAFAB 的关系**: 2026-05-19 的 SFEM+IRAFAB 是同类范式（非对称骨干），但两者 mAP50 均未达 0.865 阈值已删除。本方案改用 mAP50>0.865 的 COI+DASI 组合，是此范式的改进演进

**架构设计**:

```
                       非对称骨干架构

  Input(4ch)
    ├──[0:3]──→ SilenceChannel ──→ RGB 分支
    │                               │
    │          ┌── COI 三重残差 (纹理增强) ──────────────┐
    │          │                                      │
    │          │  层2:  COI[64,3,2]  → P1/2 (s=2)    │
    │          │  层3:  COI[128,3,2] → P2/4 (s=2)    │
    │          │  层5:  COI[256,3,2] → P3/8 (s=2)    │
    │          │                                      │
    │          └──────────────────────────────────────┘
    │
    └──[3:4]──→ SilenceChannel ──→ IR 分支
                                    │
              ┌── DASI 残差增强 (小目标增强) ────────────┐
              │                                       │
              │  层12: DASI[64,2]  → P1/2 (s=2)      │
              │  层13: Conv[128,3,2] → P2/4           │
              │  层15: Conv[256,3,2] → P3/8           │
              │                                       │
              └───────────────────────────────────────┘

           两分支 stride 对齐 → Concat 融合 (P3/P4/P5)
```

COI 内部结构 (三重残差):

```
         input
           │
       ┌───┴───┐
       │ proj  │  1×1 Conv (通道对齐 + stride)
       └───┬───┘
           │
   ┌───────┼───────┐
   │       │       │
┌──┴──┐┌───┴──┐┌───┴──┐
│ BN  ││DWConv││ 1×1  │  ① 恒等+BN  ② 深度卷积  ③ 逐点卷积

### DASI-ProgAgg: Backbone+Neck 双层组合增强

> **创新等级**: ⭐ (系统创新 — 验证 backbone+neck 叠加效果)
> **改装自**: DASI (多空洞率, 来源: 红外小目标检测 2024, mAP50=0.886 精度第1) + ProgressiveAgg (PLF+LCAR, 来源: rmae ProGRess 分割头, mAP50=0.8654 速度第1)
> **mAP50**: 待训练（源模块: DASI=0.886, ProgressiveAgg=0.8654）
> **无代码改动**: 复用现有模块

**核心创新**:
- **双层叠加链路**: DASI 浅层大空洞率增强小目标 → ProgressiveAgg 渐进多尺度聚合，形成"浅层增强→多层聚合"完整链路
- **分辨率协同**: DASI 无 stride → backbone 输出分辨率提升一级 → ProgressiveAgg 的 F.interpolate 自适应匹配
- **互补验证**: DASI(精度第1) + ProgressiveAgg(速度第1)，验证精度与速度最优模块的组合是否产生叠加效果

**架构设计**:

```

  │                                                       │

  │  proj      proj       proj     ← 1×1 通道对齐          │
  │   │          │          │                             │

  │   │     └────┬────┘                                   │
  │   │     ┌────┴────┐                                   │
  │   │     │  LCAR   │ → P4''    (通道门控+残差)           │

  │         ┌────┴────┐                                  │

ProgressiveAgg 内部流程:

```
  Step 1: 投影 — P3/P4/P5 各经 1×1 Conv 对齐到统一通道 c2

  Step 2: PLF 渐进融合 (从深到浅)
          P5 → Upsample → Concat(P4, P5↑) → 1×1 → P4'
          P4' → Upsample → Concat(P3, P4'↑) → 1×1 → P3'

  Step 3: LCAR 轻量通道注意力残差
          fused_i → 1×1 Conv → Sigmoid → 逐通道加权 → + fused_i (残差)

  Step 4: Bottleneck 融合
          全部上采样到 P3 分辨率 → Concat → 1×1+BN+GELU → output
```

## 2026-08-04

### DAIFusion: 基于原型相似度的深度自适应注入融合

> **创新等级**: ⭐⭐⭐ (论文级 — 首次将原型对比学习引入 RGB-T 融合)
> **来源论文**: VCP-DCN (ECCV 2026) — DAI (Depth Adaptive Injection) 的跨模态扩展
> **mAP50**: 待训练（源任务: RGB-D 伪装目标检测 SOTA）

---

#### 一、问题定义

**RGB-T 融合的核心痛点 — 模态同质化**: Concat 融合简单拼接 RGB 和 IR 特征, 两模态在统一监督下趋向同质化, 丢失模态特异性:

| 融合方法 | 问题 |
|----------|------|
| Concat | 通道拼接, 无模态交互, 信息冗余 |
| Add | 直接相加, 假设两模态贡献相等 |
| Cross-Attention | O(N²) 复杂度, 且融合后特征趋同 |
| 门控融合 | 仅在通道/空间维度加权, 未显式保留模态独特信息 |

**关键洞察**: RGB 纹理和 IR 热辐射是物理特性截然不同的模态, 融合时应**显式区分一致性信息（两模态共享的）和特异性信息（各模态独有的）**, 而非简单混合。

---

#### 二、核心创新: 原型引导的自适应注入

##### 2.1 论文原版 DAI 机制

VCP-DCN 针对伪装目标检测提出渐进式框架 SPE → MDA → DAI:
- **SPE**: 掩码池化提取前景/背景原型 → 原型对比损失(一致性+特异性+前景-背景)
- **MDA**: 原型-特征响应图 → 掩码线性注意力跨模态交互
- **DAI**: 原型相似度 → 自适应权重 → 一致性/特异性分解 → 可变形卷积融合

##### 2.2 RGB-T 适配设计

```
  RGB ──→ Proj ──→ GAP ──→ cos_sim(·, P_con) ──→ sim_rgb ──┐
                                                              │
  P_rgb_s ──→ cos_sim(·, P_con) ──→ proto_sim_rgb ──────────┤
                                                              ├─→ W_r = sigmoid(sim_rgb + proto_sim_rgb)
  IR  ──→ Proj ──→ GAP ──→ cos_sim(·, P_con) ──→ sim_ir ───┐│
                                                            ││
  P_ir_s  ──→ cos_sim(·, P_con) ──→ proto_sim_ir ───────────┤│
                                                            ├┴─→ W_d = sigmoid(sim_ir + proto_sim_ir)

  F_c     = W_r · rgb + W_d · ir          一致性特征 (两模态共享信息)
  F_s_rgb = (1 - W_r) · rgb                RGB 特异性 (独有纹理/边缘)
  F_s_ir  = (1 - W_d) · ir                 IR 特异性 (独有热辐射)

  concat(F_c, F_s_rgb, F_s_ir) → 1x1 Conv(3c2→c2) → GroupNorm → SiLU → DWConv3x3 → Out
```

##### 2.3 核心组件

| 组件 | 参数量 | 作用 |
|------|--------|------|
| proj_rgb/proj_ir | 2×c_in×c2 | 1×1 通道对齐 |
| P_con, P_rgb_s, P_ir_s | 3×c2 | 可学习原型 (SPE 简化) |
| GAP + cos_sim | 0 | 内容-原型相似度 (DAI 核心) |
| reduce (1×1 Conv) | 3×c2×c2 | 3 路特征融合 |
| refine (DWConv3×3) | c2×9 | 空间细化 |

---

#### 三、为什么是论文级创新

##### 3.1 首次实现

1. **首次**将原型对比学习从 RGB-D 伪装检测扩展到 **RGB-T 目标检测融合**
2. **首次**在融合点显式分解**一致性特征和特异性特征**, 而非简单加权或拼接
3. **首次**用可学习原型替代掩码池化, 使原型学习适用于无像素级标注的检测任务

##### 3.2 与现有方法对比

| 方法 | 融合域 | 模态特异性保留 | 原型引导 | 复杂度 |
|------|--------|---------------|----------|--------|
| Concat | 通道域 | ✗ | ✗ | O(1) |
| CIFusion | 通道域 | ✗ | ✗ | O(C²) |
| vHeat_Fusion | 频域 | ✗ | ✗ | O(N^1.5) |
| FCMMFusion | 空域 | 部分(交叉门控) | ✗ | O(C·H·W) |
| **DAIFusion** | **空域** | **✓ (显式分解)** | **✓ (可学习原型)** | **O(C·H·W)** |

DAIFusion 是唯一**显式保留模态特异性**的融合方法, 且通过原型引导实现内容自适应决策。

##### 3.3 可解释性

- W_r 大 → RGB 与一致性原型对齐度高 → RGB 贡献更多一致性信息
- W_d 大 → IR 与一致性原型对齐度高 → IR 贡献更多一致性信息
- (1-W) → 提取该模态的特异性信息, 保留独有特征
- 原型间相似度 → 可学习偏置, 反映模态间固有关系
