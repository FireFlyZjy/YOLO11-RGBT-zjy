## 2026-05-19

### CIFusion: 跨模态交叉交换融合

> **创新等级**: ⭐⭐ (架构创新 — 将 CMFADet 的交叉交换机制引入 YOLO RGB-T 融合)
> **来源论文**: CMFADet — Cross-Modal Feature Alignment for RGB-Infrared Object Detection

**核心创新**:
- **交叉交换 (Cross-Exchange)**: 不是简单 Concat 或加权融合。RGB 和 IR 分别做通道注意力门控后，**交换放置**——RGB 的注意力特征放到 IR 位置，IR 的放到 RGB 位置
- 双向信息传递: 每个模态不仅保留自身增强特征，还接收对方模态的上下文
- 比 Concat 增加 ~5.7M 参数，但提供了结构化的模态交互

**与 vHeat_Fusion 的关系**: CIFusion 在**通道域**融合，vHeat_Fusion 在**频域**融合，两者互补可级联使用。

### 非对称骨干设计: SFEM (RGB) + IRAFAB (IR)

> **创新等级**: ⭐⭐ (范式创新 — 首次在 YOLO 中实现 RGB-T 非对称骨干)
> **来源论文**: CMFADet — 空间-频率增强模块 + 自适应红外增强模块

**核心创新**:
- **首次**为 RGB 和 IR 分支设计**不同结构**的 backbone block:
  - RGB 分支: SFEM — FFT 频域增强 + Scharr 边缘检测，利用 RGB 的纹理和边缘信息
  - IR 分支: IRAFAB — 自适应多核深度卷积 + 门控线性单元 (GLU)，专为红外热辐射信号设计
- 突破了传统双模态检测中两分支共享相同架构的范式
- 每种模态使用最适合其物理特性的算子

**物理可解释性**:
- RGB 包含丰富纹理/边缘 → 用 Scharr 算子显式提取边缘 + FFT 频域分析
- IR 热辐射平滑但噪声多 → 用自适应多核 DWConv + GLU 选择性增强有效信号

### ICAFusion: 迭代交叉注意力 Transformer 融合

> **创新等级**: ⭐⭐ (架构创新 — 完整的 Transformer 跨模态融合在 YOLO 中的应用)
> **来源论文**: ICAFusion (Pattern Recognition 2023) — Iterative Cross-Attention Guided Feature Fusion

**核心创新**:
- **双交叉注意力**: RGB 和 IR 各用独立 QKV 投影 → IR query × RGB key 计算注意力（反之亦然）
- **可学习系数残差**: 8 个可学习系数控制注意力输出和 MLP 的残差比例，细粒度梯度调节
- **自适应池化**: avg+max 双池化可学习加权，将特征下采样到固定网格降低计算量
- 参数量较大 (+16.6M)，但与 vHeat_Fusion 形成互补: ICAFusion 是空域 Transformer 融合，vHeat_Fusion 是频域热传导融合

## 2026-05-26

### ATAH: 任务感知对齐检测头

> **创新等级**: ⭐⭐ (架构创新 — 分类/回归分支分离 + 可变形对齐)
> **来源论文**: CMFADet — Adaptive Task-aware Alignment Head

**核心创新**:
- **任务感知特征调制**: 全局池化→降维→Sigmoid 门控，为分类和回归分支生成不同的特征掩码
- **回归对齐 (DyDCNv2)**: 可变形卷积根据特征学习采样偏移，动态校正预测框空间位置
- **分类对齐**: 空间注意力概率图约束分类输出，抑制双模态融合引入的背景噪声
- **移植创新**: 消除 mmcv 依赖，改为 `torchvision.ops.deform_conv2d`，实现纯 PyTorch 部署

## 2026-05-27

### RGB-T 频域模块系统集成

> **创新等级**: ⭐ (系统创新 — 首次将 FFT/DCT/Gabor/小波频域模块系统应用于 RGB-T 检测)
> **来源论文**: vHeat (CVPR 2025), TOST (ICLR 2025), DarkIR (CVPR 2025), FADC (CVPR 2024), SFSConv (CVPR 2024), FDConv (CVPR 2025)

**核心创新**:
- **首次系统集成** 6 个频域模块到 RGB-T 目标检测 pipeline，覆盖 FFT/DCT/Gabor/小波四种频域变换
- 频域天然适配 RGB-T: RGB 高频纹理 + IR 低频热辐射在频域自然解耦
- 纯 PyTorch 实现，无 CUDA 扩展依赖

**模块功能分布**:
| 模块 | 频域变换 | 机制 | RGBT 价值 |
|------|----------|------|-----------|
| FDConv | FFT | 频带分解+独立调制 | IR/RGB 频率特征差异化 |
| vHeat | DCT | 热传导 exp 衰减 | 频率天然分离，全局建模 |
| TOST | 统计矩 | 二阶统计量 O(n) 注意力 | 双模态分布聚合比较 |
| FADC | FFT | 频率自适应膨胀率 | IR 热边缘保留细节 |
| EBlock/DBlock | FFT | 幅度调制+空间去模糊 | IR 低对比度增强 |
| SFSConv | FFT/小波 | 空间/频率分流融合 | RGB 纹理+IR 热信号分工 |

**与后续 vHeat_Fusion 的关系**: 此批次集成的是**单模态**频域增强模块（每个模块处理单个特征图），而 vHeat_Fusion 是**跨模态**频域融合模块（同时处理 RGB+IR 两路输入），是从"频域增强"到"频域融合"的范式升级。

## 2026-06-04

### vHeat_Fusion: 基于热传导方程的跨模态频域融合

> **创新等级**: ⭐⭐⭐ (论文级 — 首次将热传导原理引入 RGB-T 融合)
> **来源论文**: vHeat (CVPR 2025) — 热传导算子 HCO 的跨模态扩展

---

#### 一、问题定义

**RGB-T 检测的核心挑战**: 可见光(RGB)和红外(IR)是两种物理特性截然不同的模态：

| 维度 | RGB | IR |
|------|-----|-----|
| 物理原理 | 反射可见光 | 热辐射 |
| 高频分量 | 纹理/边缘丰富 | 噪声占主导 |
| 低频分量 | 光照敏感 | 稳定的热轮廓 |
| 频域特征 | 全频段信息 | 能量集中在低频 |

**现有融合方法的局限**:
1. **Concat 融合**: 简单拼接，无模态交互，信息冗余
2. **Cross-Attention 融合**: O(N²) 复杂度，计算量大
3. **门控融合**: 仅在通道维度加权，忽略频域差异

**关键洞察**: RGB 和 IR 在**频域**天然互补——RGB 的高频纹理 + IR 的低频热辐射 = 完整场景表征。但现有方法都在**空域**融合，无法显式利用这种频域互补性。

---

#### 二、核心创新: 热传导方程驱动的频域融合

##### 2.1 物理直觉

热传导方程描述了热量如何随时间在介质中扩散：

```
∂u/∂t = k · (∂²u/∂x² + ∂²u/∂y²)

频域解: U(ω, t) = U₀(ω) · exp(-k · t · |ω|²)
```

**物理解释**: 高频分量（大 |ω|）随时间指数衰减，衰减速度由热扩散系数 k 控制。

**RGB-T 映射**:
- RGB 模态 → 小 k_rgb → 缓慢衰减 → 保留高频纹理
- IR 模态 → 大 k_ir → 快速衰减 → 抑制高频噪声
- 热扩散成为**自适应频域滤波器**，对不同模态自动调节截止频率

##### 2.2 架构设计

```
                    ┌─────────────────────────────────┐
                    │        vHeat_Fusion              │
                    │                                   │
  RGB ──→ Proj ──→ DCT ──→ k_rgb预测 ──→ 衰减_rgb ──┐ │
                    │                                  ├─→ 跨模态 ──→ IDCT ──→ Out
  IR  ──→ Proj ──→ DCT ──→ k_ir 预测 ──→ 衰减_ir ──┘ │    门控
                    │                                   │
                    └─────────────────────────────────┘

详细流程:
  Step 1: RGB/IR 分别 1×1 投影到统一通道数 c2
  Step 2: 2D DCT 将空域特征变换到频域 (矩阵乘法, O(N^1.5))
  Step 3: 自适应预测模态特定热扩散系数 k_rgb, k_ir ∈ (0, 1)
          - k 从 GAP 特征通过 FC+ReLU+Sigmoid 预测
          - 内容自适应: 不同图像/通道有不同的 k
  Step 4: 频域热扩散衰减
          - dct_rgb' = dct_rgb · exp(-k_rgb · t · freq²)
          - dct_ir'  = dct_ir  · exp(-k_ir  · t · freq²)
  Step 5: 跨模态频率门控
          - 拼接两模态频域特征 → GAP → FC → Sigmoid → 拆分为 gate_rgb, gate_ir
          - dct_fused = gate_rgb · dct_rgb' + gate_ir · dct_ir'
          - 门控在频域操作，决定每个频率分量来自哪个模态
  Step 6: 2D IDCT 恢复空域 + 输出投影 + BN + SiLU
```

##### 2.3 核心算子复杂度

| 算子 | 复杂度 | 对比 |
|------|--------|------|
| vHeat_Fusion (DCT/IDCT) | O(C · N^1.5) | N=特征图边长 |
| Self/Cross-Attention | O(C · N²) | — |
| 加速比 (N=20, P5) | ~4.5× | 20² / 20^1.5 ≈ 89 / 20 ≈ 4.5× |

---

#### 三、为什么这是论文级创新

##### 3.1 首次实现
1. **首次**将热传导方程从单模态 backbone 扩展到**跨模态融合**
2. **首次**在 DCT 频域进行 RGB-T 自适应融合（而非空域或通道域）
3. **首次**利用热扩散系数的物理意义实现模态特定的频率选择性

##### 3.2 与现有方法的关系

| 方法 | 融合域 | 模态交互 | 复杂度 |
|------|--------|----------|--------|
| Concat (基线) | 通道域 | 无 | O(1) |
| CIFusion (通道注意力融合) | 通道域 | 通道加权 | O(C²) |
| ICAFusion (交叉注意力) | 空域 | 全局 | O(N²) |
| AFF (注意力特征融合) | 多尺度 | 局部 | O(N) |
| **vHeat_Fusion (本方法)** | **频域** | **频率门控** | **O(N^1.5)** |

vHeat_Fusion 是**唯一在频域工作**的融合方法，填补了 RGB-T 融合在频域的空白。

##### 3.3 物理可解释性
- k_rgb 小 → RGB 高频保留 → 纹理/边缘信息保留 → 可解释为"纹理保留系数"
- k_ir 大 → IR 高频抑制 → 热噪声去除 → 可解释为"噪声抑制系数"
- 频率门控在 DCT 域 → 显式选择每个频率分量的模态来源 → 可解释为"频谱分配"

## 2026-06-20

### FCMMFusion: 跨分支交叉门控融合

> **创新等级**: ⭐⭐ (架构创新 — 将 FCM 的 Cross-Gating 机制改造为 RGB-T 双模态融合)
> **来源**: FCM-main (FCM/FCM_1/FCM_2/FCM_3 系列模块的思想) 改造

#### 一、问题定义

RGB-T 检测中，双模态融合的核心挑战是如何让两种模态**互相增强**而非简单叠加：
- Concat: 通道拼接，无模态交互
- Add: 直接相加，假设两模态贡献相等
- CIFusion: 通道域交叉交换，但不区分空间和通道维度

需要一种机制，能**分维度**地让一种模态去门控另一种模态：
- 空间维度: IR 的热辐射分布告诉 RGB "哪些区域重要"
- 通道维度: RGB 的纹理特征告诉 IR "哪些通道有效"

#### 二、核心创新机制

**FCMMFusion** 的双路交叉门控设计：

```
vis ──→ 1x1 Proj ──→ vis_feat ──→ × SpatialGate(ir_feat) ──→ vis_gated ──┐
ir  ──→ 1x1 Proj ──→ ir_feat  ──→ × ChannelGate(vis_feat) ──→ ir_gated ──┤──→ Fusion → output
```

1. **空间门控 (SpatialGate)**: 对 ir_feat 做 Conv1x1→GroupNorm→SiLU→Conv1x1→Sigmoid，生成空间注意力掩码，作用于 vis_feat。IR 的热辐射区域自然高亮，帮助 RGB 聚焦目标。
2. **通道门控 (ChannelGate)**: 对 vis_feat 做 GAP→Conv1x1→GroupNorm→SiLU→Conv1x1→Sigmoid，生成通道注意力权重，作用于 ir_feat。RGB 的纹理信息帮助 IR 选择有效通道。

**设计选择**:
- GroupNorm 替代 BatchNorm: 兼容 P5 层空间 1x1 + batch_size=1 的模型初始化场景
- ratio=4 中间通道压缩: 平衡参数量和表达能力
- 无额外位置编码: 空间门控本身隐式编码了空间位置信息

#### 三、与现有方法对比

| 方法 | 融合域 | 门控维度 | 参数量 | 复杂度 |
|------|--------|----------|--------|--------|
| Concat | 通道域 | 无 | 0 | O(1) |
| CIFusion | 通道域 | 通道(交叉交换) | +5.7M | O(C²) |
| vHeat_Fusion | 频域 | 频率(热传导衰减) | +6.3M | O(N^1.5) |
| **FCMMFusion** | 空域 | 空间+通道(双路交叉) | +3.5M | O(C·H·W) |

**独特性**: FCMMFusion 是唯一在空域同时做空间门控和通道门控的跨模态融合模块，且两路门控信息来源相反（空间门控来自 IR，通道门控来自 RGB）。

#### 四、消融实验建议

1. **门控组合消融**: 仅空间门控 vs 仅通道门控 vs 双路门控
2. **门控来源消融**: 空间门控来自 vis vs 来自 ir
3. **与 CIFusion 级联**: FCMMFusion + CIFusion vs 独立使用
4. **与 vHeat_Fusion 互补**: FCMMFusion(空域) + vHeat_Fusion(频域) 级联
5. **ratio 参数**: ratio=2/4/8 对参数量和性能的影响

|------|------|

## 2026-06-21

### EI2Det 创新点改造: 差分融合 + 质量感知 + 边缘混合

> **创新等级**: ⭐⭐ (架构创新 — 将 EI2Det 三大机制改造为即插即用RGBT融合模块)
> **来源**: EI2Det-master (Emerging Image Dual-modal Detection)

#### 一、问题定义

EI2Det提出了三个互补的融合机制, 但原始实现绑定在特定架构上(需要原始图像输入、多尺度CNN等), 无法直接用于我们的YOLO RGBT框架。

#### 二、核心创新机制

1. **DMAF差分融合**: vis-ir差分图 → GAP → tanh → 交叉加权。关注模态间差异而非各模态自身特征。
2. **QualityWeightedFusion质量感知**: GAP(vis+ir) → MLP → softmax → [w_vis, w_ir]。模拟EI2Det的天气感知但用特征级统计替代原始图像。
3. **EdgeBlendFusion边缘混合**: Sobel(vis)+Sobel(ir) → edge_proj → (1-alpha)*fused + alpha*edge。保留边缘细节。
4. **EI2Fusion全流程**: 质量加权 + 边缘混合的两阶段流水线。

#### 三、与现有方法对比

| 方法 | 融合域 | 核心机制 | 额外参数 |
|------|--------|----------|----------|
| CIFusion | 通道域 | 通道注意力交叉交换 | ~5.7M |
| vHeat_Fusion | 频域 | DCT热传导融合 | ~6.3M |
| FCMMFusion | 空域门控 | 空间+通道双路交叉门控 | ~3.5M |
| **DMAF** | 差分域 | 差分图交叉加权 | ~0M |
| **QualityWeightedFusion** | 质量域 | 特征级质量预测加权 | ~0.4M |
| **EdgeBlendFusion** | 边缘域 | Sobel边缘可学习混合 | ~0.8M |
| **EI2Fusion** | 混合域 | 质量加权+边缘混合 | ~1.2M |

#### 四、消融实验建议

1. 差分融合(DMAF) vs 直接融合(Concat)
2. 质量感知加权 vs 固定权重
3. 边缘混合 vs 无边缘混合
4. EI2Fusion全流程 vs 各组件独立
5. DMAF+EI2Fusion级联
