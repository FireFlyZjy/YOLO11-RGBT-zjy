# DASI 创新点（Dimension-Aware Selective Integration · 维度感知选择性集成）

> 模块位于 `ultralytics/nn/ExtraModules/attention/DASI.py`。
> ⚠️ **归属声明**：DASI 为**复现 / 移植**自既有文献（维度感知选择性集成，原用于红外小目标检测，2024），**并非本工作的原创贡献**。本文件用于论文中将其作为"大规模 RGB-T 融合基准中的高分复现基线"来描述，请务必保留原始出处引用，切勿作为本文创新点声称。

## 1. 机制概述
DASI 通过**跳跃连接 + 多尺度空洞聚合 + 选择性融合**增强特征响应：
1. 1×1 投影（`proj`）；
2. `Bag` 模块：4 条并行空洞卷积分支（dilation = 2/4/6/8）+ 1×1 拼接融合，做**多尺度特征聚合**；
3. 尾部卷积融合 + 跳跃连接（`x + x_skip`）+ BN + ReLU。

## 2. 为何在 RGB-T 检测中得分高
- **维度/尺度选择性**：多空洞率聚合强化红外通道在小目标上的响应（源自其红外小目标检测背景）。
- 跳跃连接缓解退化，训练稳定。
- 在 FLIR（yolo26s, RGBT-4ch, imgsz640）上 mAP50-95 = **0.5232**，仅次于 DWR。

## 3. 实测指标（FLIR, yolo26s, 100 epoch, imgsz640, RGBT-4ch）
| 指标 | 数值 |
|---|---|
| mAP50 | 0.8860 |
| mAP50-95 | **0.5232** |
| FLOPs(G) | 142.46 |
| Params(M) | 15.57 |
| FPS | 23.66 |

> 代价：算力较高（142.5G），FPS 23.7，属"精度优先"型基线。

## 4. 在本文中的定位
DASI 与 DWR、COI 共同构成基准中的**高分复现基线三强**，用于对照说明：高分模块普遍依赖大算力；本文 DCAF 的目标是在可控算力下逼近甚至超越该组基线的精度。
