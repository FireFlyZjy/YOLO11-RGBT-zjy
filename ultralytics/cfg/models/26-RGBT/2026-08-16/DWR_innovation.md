# DWR 创新点（Dilated-Wise Residual Attention · 可扩张残差注意力）

> 模块位于 `ultralytics/nn/ExtraModules/attention/DWR.py`。
> ⚠️ **归属声明**：DWR 为**复现 / 移植**自既有文献的模块（可扩张残差注意力，Dilated-Wise Residual），**并非本工作的原创贡献**。本文件用于论文中将其作为"大规模 RGB-T 融合基准中的高分复现基线"来描述，请务必保留原始出处引用，切勿作为本文创新点声称。

## 1. 机制概述
DWR 通过**多空洞率并行分支**捕获不同尺度目标特征，再以残差方式加回：
1. 1×1/3×3 卷积降维；
2. 三条并行空洞卷积分支（dilation = 1, 3, 5）；
3. 多尺度拼接 → 1×1 融合 → **残差连接**加回输入。

```
x → conv_3x3 → {conv_d1, conv_d3, conv_d5} → concat → conv_1x1 → + x
```

## 2. 为何在 RGB-T 检测中得分高
- **多尺度感受野**：dilation 1/3/5 同时覆盖小目标与中大目标，适配 RGB-T 中尺度差异大的行人/车辆。
- **残差结构**保持梯度稳定，易训练。
- 在 FLIR（yolo26s, RGBT-4ch, imgsz640）上达到本基准**最高 mAP50-95 = 0.5262**。

## 3. 实测指标（FLIR, yolo26s, 100 epoch, imgsz640, RGBT-4ch）
| 指标 | 数值 |
|---|---|
| mAP50 | 0.8830 |
| mAP50-95 | **0.5262**（基准最高） |
| FLOPs(G) | 158.61 |
| Params(M) | 15.26 |
| FPS | 19.44 |

> 代价：计算量最大（158.6G），实时性最差（19.4 FPS），属"精度优先"型基线。

## 4. 在本文中的定位
DWR 作为**精度上界参考**出现在大规模基准里，用于说明："即便采用强力的多尺度残差注意力，其高算力代价限制了部署；相比之下，本文 DCAF 以远低算力实现局部互补融合"。
